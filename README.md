# World News — 21 November 2026

A one-day world news front page for Saturday, 21 November 2026: the
Wall Street rout, Russian missiles landing in Poland, the Junín
earthquake, COP31, the reported FBI database hack, and the
daraxonrasib cancer trial — plus an in-brief box with four more items.

`draw_image.py` draws `entry.png` (1024×1024) with Python and Pillow;
run `python3 draw_image.py` in this directory to regenerate it.
`main.ts` copies `entry.png` to the output directory, byte for byte.

## The six stories

1. **New York:** US stocks fall 3.7% as the AI sell-off deepens; the S&P 500 enters correction and the Nasdaq drops 5.3%, wiping out all of its 2026 gains.
2. **Warsaw:** Russian missiles land in Poland; Prime Minister Tusk calls it a deliberate provocation as allied leaders rally to Warsaw.
3. **Junín:** A magnitude 6.8 earthquake strikes Peru's Andes and is felt in Lima, about 320 km away.
4. **Antalya:** COP31 climate talks run past their deadline as nearly 200 nations fail to agree over fossil fuels.
5. **Washington:** The FBI investigates a reported breach of its national crime database amid continuing computer outages in the US.
6. **London:** The pill daraxonrasib makes tumours undetectable on scans in one in 12 patients in an early pancreatic cancer trial.

## Run

Generate the 1024×1024 PNG with Python 3 and Pillow:

```sh
python3 draw_image.py
```

Copy the generated image into the make.fun output directory with Node 22:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program runs twice and both runs write the same bytes.
